# AI 드라마 작가실

막장 숏폼 드라마/웹소설을 위한 Story Bible 기반 집필 도구입니다.

## 핵심 기능

- 작품의 최종 진실(작가 전용), 인물, 혈연, 관계, 연표, 떡밥 관리
- 규칙 기반 1차 설정 오류 검사
- AI 4단계 회차 파이프라인
  1. 구성 작가: 회차 비트 설계
  2. 대본 작가: 촬영 가능한 초고 작성
  3. 설정 감사: 혈연/연표/지식범위/떡밥 충돌 검사
  4. 편집장: 오류를 반영한 최종본 작성
- 프로젝트를 JSON으로 백업/복원
- 회차별 초고/감사보고서/최종본 저장

## 실행 방법

### 1. Python 설치
Python 3.10 이상을 권장합니다.

### 2. 폴더에서 패키지 설치

```bash
pip install -r requirements.txt
```

### 3. 실행

```bash
streamlit run app.py
```

브라우저가 열리면 사이드바에 OpenAI API Key를 입력합니다.

## 모델 선택

기본값은 `gpt-5.6-terra`입니다. 비용보다 품질을 우선하는 최종 설정 설계/검수에는 `gpt-5.6-sol`, 반복 작업에는 `gpt-5.6-luna`를 선택할 수 있습니다.

## 권장 사용 순서

1. **작품** 탭에서 로그라인과 `작가만 아는 최종 진실`을 먼저 확정합니다.
2. **인물** 탭에서 친모/친부를 명시합니다.
3. **관계**와 **연표**를 입력합니다.
4. **설정 감사**를 먼저 실행합니다.
5. **떡밥**을 입력합니다.
6. **회차 집필**에서 그 화에 반드시 일어날 사건만 지정하고 실행합니다.

## 중요한 설계 원칙

이 프로그램은 “매번 기억에 의존해 소설을 쓰는 챗봇”이 아니라, 저장된 Story Bible을 매 회차 앞에 붙이고 별도 감사 역할이 초고를 검사하도록 설계되어 있습니다. 그래도 AI 검수는 완전무결하지 않으므로, 규칙 기반 검사와 Story Bible을 함께 유지하는 것이 핵심입니다.

## 데이터

모든 프로젝트 데이터는 같은 폴더의 `project.json`에 저장됩니다. 앱 사이드바에서 JSON으로 내려받아 백업할 수 있습니다.
